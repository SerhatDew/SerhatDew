# Hi, I'm Serhat

Most of my work here is Minecraft plugins and Discord bots. Mainly Java and TypeScript.

[blokoyun.com](https://blokoyun.com) / [turkiyemc.com](https://turkiyemc.com)

### Some of my projects

- [sarki-tahmin](https://github.com/SerhatDew/sarki-tahmin) — a song and image guessing bot for Discord.
- [uxmFarmerOtoEritme](https://github.com/SerhatDew/uxmFarmerOtoEritme) — automatic ore smelting for uxmFarmer.
- [AxSpawnerFarmerHook](https://github.com/SerhatDew/AxSpawnerFarmerHook) — sends AxSpawners loot to uxmFarmer.

### Minecraft plugin forks

- [AxVaults](https://github.com/SerhatDew/AxVaults) — Java 25 and Paper 26.2 support, multi-server vault sync with MySQL or Redis, and fail-closed ownership locks to prevent duplicate edits.
- [AxTrade](https://github.com/SerhatDew/AxTrade) — Java 25 and Paper 26.2 support, SQL storage for trade logs and preferences, Redis settings sync, and experimental cross-server trading.
- [Custom-Nameplates](https://github.com/SerhatDew/Custom-Nameplates) — updated for Java 25 and Paper 26.2, with fixes for fake players and channels.
- [Custom-Fishing](https://github.com/SerhatDew/Custom-Fishing) — Java 25 and Paper 26.2 support, updated platform dependencies, and item durability fixes.
- [ODailyQuests](https://github.com/SerhatDew/ODailyQuests) — Java 25 and Paper 26.2 support, MySQL multi-server sync, and quest reload/save fixes.
- [IllegalStack](https://github.com/SerhatDew/IllegalStack) — Java 25 and Paper 26.2 updates, exploit protection patches, and startup chat fixes.
- [minecraft-leaderos-auth](https://github.com/SerhatDew/minecraft-leaderos-auth) — in-game auth for LeaderOS, with configurable connection limits per IP.
- [InteractiveChat](https://github.com/SerhatDew/InteractiveChat) — chat click and hover events with log filter fixes and startup compatibility.
- [HeadBlocks](https://github.com/SerhatDew/HeadBlocks) — world head hunt and rewards plugin with updated menu and action bar assets.
